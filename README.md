**Завдання 1. Пошук максимального та мінімального елементів**\
Реалізуйте функцію, яка знаходить максимальний та мінімальний елементи в масиві, використовуючи метод «розділяй і володарюй».

_Результати виконання:_\
Реалізовано: функцію find_min_max(arr, left, right), яка знаходить мінімальний та максимальний елементи масиву, використовуючи рекурсивний підхід “розділяй і володарюй”.

Перевірено: функцію на масиві з 20 елементів\
arr = [21, -4, 1, 91, -60, 7, -3, 52, -8, 44, 0, -2, 6, -1, 3, -7, 8, -54, 19, -9]


_Результат:_\
Мінімальний елемент: -60
Максимальний елемент: 91

Повертається: кортеж (мінімум, максимум)

minimum, maximum = find_min_max(arr, 0, len(arr) - 1)


_Перевірка часової складності:_\
для масивів розміром n = 1000, 5000, 10000, 20000, 40000\
Замір часу показав приблизно лінійну залежність:\
n=1000, час виконання ≈ 0.000000 секунд\
n=5000, час виконання ≈ 0.002004 секунд\
n=10000, час виконання ≈ 0.001998 секунд\
n=20000, час виконання ≈ 0.003011 секунд\
n=40000, час виконання ≈ 0.007293 секунд

**Висновок: алгоритм працює коректно, повертає мінімум і максимум, використовує рекурсію, а час виконання лінійно залежить від розміру масиву, що підтверджує O(n).**

**Завдання 2. Оптимізація черги 3D-принтера в університетській лабораторії**\
Розробіть програму для оптимізації черги завдань 3D-друку з урахуванням пріоритетів та технічних обмежень принтера, використовуючи жадібний алгоритм.

Опис завдання
1. Використовуйте вхідні дані у вигляді списку завдань на друк, де кожне завдання містить: ID, об'єм моделі, пріоритет та час друку.\
2. Реалізуйте основну функцію optimize_printing, яка буде:\
Враховувати пріоритети завдань.\
Групувати моделі для одночасного друку.\
Перевіряти обмеження об'єму та кількості.\
Розраховувати загальний час друку.\
Повертати оптимальний порядок друку.
3. Виведіть оптимальний порядок друку та загальний час виконання всіх завдань.

_Результати виконання:_\
Реалізовано: функцію optimize_printing, яка оптимізує чергу 3D-друку з урахуванням пріоритетів та обмежень принтера.\
Перевірено роботу на трьох тестових сценаріях: однаковий пріоритет, різні пріоритети, перевищення обмежень.\
Використано жадібний алгоритм: на кожному кроці групуємо максимальну кількість доступних завдань для одночасного друку без перевищення обмежень.\
Враховані пріоритети: завдання з вищим пріоритетом друкуються раніше.\
Час друку групи визначається як максимальний час серед моделей у групі.

_Результат:_\
Тест 1 (однаковий пріоритет):\
Порядок друку: ['M1', 'M2', 'M3']\
Загальний час: 270 хвилин

Тест 2 (різні пріоритети):\
Порядок друку: ['M2', 'M1', 'M3']\
Загальний час: 270 хвилин

Тест 3 (перевищення обмежень принтера):\
Порядок друку: ['M1', 'M2', 'M3']\
Загальний час: 450 хвилин
